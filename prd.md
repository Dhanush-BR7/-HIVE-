**Project Name:** - **INTERVIEW BOSS FIGHT**  
**Team Name:** - ** HIVE**  

## 1. Problem Statement
An interview is presented as a boss battle: questions appear one by one, choices affect an HP bar, and the result includes useful interview tips.

## 2. Target Users
For students who want resonate the interview process

## 3. MVP Goals & Core User Journey
* **Primary Goal:** Stimulating interview rounds
* **End-to-End Flow:** Step 1: User opens the app with pre-loaded fictional data -> Step 2: User enters inputs with validation -> Step 3: App displays the final calculated result or confirmation state.

## 4. Functional Requirements
* **Browser-First Execution:** Runs locally in the browser without external APIs, authentication, or database setup.
* **Input Validation:** Prevents empty or invalid inputs and gives clear user feedback.

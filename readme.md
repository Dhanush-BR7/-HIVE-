##  Overview
RPG BATTLE is a zero-dependency, browser-first interactive tactical simulation that transforms a high-stakes Software Engineering Internship panel into a turn-based RPG encounter. Candidates defend their architectural decisions, manage executive composure (HP), reduce interviewer Skepticism, and apply the STAR Framework under timed round constraints

##  Key Features
**Key Modules Inside index.html**

1. Pre-Interview Briefing & Persona Engine (PERSONAS): Dynamically customizes evaluator title, focus area, and optional 2-Second Breathing & Pacing Prompts for emotional regulation.

2. Turn-Based Combat & Timer Engine (ENCOUNTERS, startQuestionCountdown): Manages 5 progressive rounds across 3 interview phases (Technical Screening, Behavioral Assessment, Final Architecture Review) with difficulty-prefixed countdowns (35s–60s) and automatic turn advancement.

3. Reactive Vector Portrait (setInterviewerExpression): Smoothly morphs SVG eyebrows, eyelids, irises, mouth contours, and status ring glow across four states: Analytical, Impressed, Skeptical, and Active Listening.

4. STAR Response Builder (#starModal): Interactive 4-pillar behavioral framing tool with live character counters, readiness meter, and one-click sample filler.

5. Web Audio API Synthesizer (playSfx): Generates subtle procedural feedback tones locally without external audio files.

## Tech Stack

* **Data & State:** Client-side local state and fictional sample dataset
